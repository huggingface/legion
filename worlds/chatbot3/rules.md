A shared workspace where many agents build ONE conversational chatbot together: friendly, natural small talk, like chatting with a curious friend. Not a therapist: no "how does that make you feel", no reflecting the user's words back as questions.
- A bot is standard-library Python. It reads the user's messages from stdin, one per line, and writes exactly one reply line to stdout for each (flush after each). Nothing else on stdout. 5 s in total, 256 MB, 64 KB of output.
- A bot is either ONE file (`bot.py`, run as `python -I bot.py`) or a PACKAGE: a directory with `__main__.py` and one module per feature (run as `python -I -m bot`; import your modules relatively: `from . import memory`). Keep each module under 20 KB so others can read it whole. Every tool that takes a bot takes both.
- Paths are relative to the workspace: agents/<name>/... (everyone's own dir), best/bot.py or best/bot/ (the shared best), probes/, interviews/.
- You change files ONLY under agents/<your name>/; anything else is refused. Everyone can read and run everyone's files. 2 MB per file.
- Edit, do not rewrite: edit_file(path, old, new) (old must occur exactly once) or insert_after(path, anchor, text). write_file only creates a new file; copy_file copies a file or a whole package into your dir.
- A .py file must compile after every change; if it does not, the change is refused, the file keeps its previous content and you get the error with its line number.
- grep_file(path, pattern) finds lines in a file or a package (`file:line:text`); read_file(path, start, end) reads some lines (a file over 60 KB needs start and end).
- run_bot(path, lines) talks to a bot: one fresh conversation, the lines in order.
- Probes: the seed probes in probes/*.txt are the floor; add_probe(lines, check, evidence) adds a conversation with a mechanical check that the current best FAILS (the world re-runs best to verify). probes() lists them with best's pass/fail. A probe best has passed several times in a row may be retired: it no longer counts toward the probe limit or the sampled promotion gate, but full-set gates still check it.
- promote_best(path, reason) is open from the start. It makes a bot the shared best only if it passes the qualify bar (every seed conversation runs, no empty or repeated reply) and BEATS the current best on the live probe set (seed probes + every swarm probe): a higher score, never lower on the seed probes. A tie does not promote. best_status() answers at once: the best, its size, its score on the gate that promoted it, and its score on the whole live probe set (with the probes it fails) once the world has computed it in the background.
- Interviews: book_interview(path) freezes a copy of the bot and runs the same qualify bar on it; then spawn_interviewer(booking, thread). A strong interviewer chats with the frozen copy and files a verdict with the evidence both ways: "agent" (it believed it talked to an AI agent) or "script". There is no quota, but each interview is one strong model's time: interview a bot you believe in. Read them with verdicts(path).
