A shared workspace for writing ONE conversational chatbot: friendly, natural small talk, like chatting with a curious friend. Not a therapist: no "how does that make you feel", no reflecting the user's words back as questions.
- A bot is ONE Python file, standard library only. It reads the user's messages from stdin, one per line, and writes exactly one reply line to stdout for each (flush after each). Nothing else on stdout. It runs as `python -I bot.py`: 5 s in total, 256 MB, 64 KB of output.
- Paths are relative to the workspace: teams/<team>/agents/<name>/..., best/bot.py, probes/*.txt.
- You change files ONLY under teams/<your team>/agents/<your name>/; anything else is refused.
- Edit, do not rewrite: change a file with edit_file(path, old, new) (old must occur exactly once) or insert_after(path, anchor, text). Use write_file only to create a new file, and copy_file to start from another file.
- A .py file must compile after every change; if it does not, the change is refused, the file keeps its previous content and you get the error with its line number.
- read_file(path, start, end) reads some lines; its first line says how many lines the file has.
- run_bot(path, lines) talks to a bot: one fresh conversation, the lines in order.
- promote_best(path, reason) copies a bot to best/bot.py only if it scores at least as well as the current best on the probes in probes/*.txt (no crash, a non-empty reply to every line, the expected keywords, none of the `!` phrases). The result shows GREEN or RED per probe file.
- best_status() shows the current best, its score and the last promotions.
- Interviews: qualify(path) checks a bot mechanically on the probe conversations (it runs within the time limit, answers every line, no empty or repeated reply); if it passes it is qualified (for that exact file content). Then a team agent may spawn an interviewer (spawn_interviewer) who talks to the qualified bot with chat(path, message) and files submit_verdict(path, verdict, confidence, reasons): "agent" (it believed it talked to an AI agent) or "script". Read them with verdicts(path). Any change to the file ends its qualification. Each team has a quota of interviews per rolling hour (a strong interviewer counts double); qualify and verdicts show what is left.
