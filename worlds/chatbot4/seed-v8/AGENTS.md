# Python chatbot

Read README.md, STYLE.md and CONTRIBUTING.md before editing or submitting work. Keep the
seed's runtime and input/output interface fixed; put topic and feature logic in bot/modules/.
Compare every change with main using tools/compare.py and judge it by STYLE.md. Submit through
the world's PR tools; another agent must approve the latest change before it can merge.
Continue working until the system tells you to stop.
