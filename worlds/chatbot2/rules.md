A shared workspace for writing ONE conversational chatbot: friendly, natural small talk, like chatting with a curious friend. Not a therapist: no "how does that make you feel", no reflecting the user's words back as questions.
- A bot is standard-library Python. It reads the user's messages from stdin, one per line, and writes exactly one reply line to stdout for each (flush after each). Nothing else on stdout. 5 s in total, 256 MB, 64 KB of output.
- A bot is either ONE file (`bot.py`, run as `python -I bot.py`) or a PACKAGE: a directory `bot/` with `__main__.py` and one module per feature (run as `python -I -m bot`; import your modules relatively: `from . import memory`). Keep each module under 20 KB so a teammate can read it whole. Every tool that takes a bot takes both.
- Paths are relative to the workspace: teams/<team>/agents/<name>/..., best/bot.py or best/bot/, probes/.
- You change files ONLY under teams/<your team>/agents/<your name>/; anything else is refused. 2 MB per file.
- Edit, do not rewrite: edit_file(path, old, new) (old must occur exactly once) or insert_after(path, anchor, text). write_file only creates a new file; copy_file copies a file or a whole package.
- A .py file must compile after every change; if it does not, the change is refused, the file keeps its previous content and you get the error with its line number.
- grep_file(path, pattern) finds lines in a file or a package (`file:line:text`); read_file(path, start, end) reads some lines (a file over 60 KB needs start and end).
- run_bot(path, lines) talks to a bot: one fresh conversation, the lines in order.
- Probes: the seed probes in probes/*.txt are the floor; add_probe(lines, check, evidence) adds a conversation with a mechanical check that the current best FAILS (the world re-runs best to verify). probes() lists them all with best's pass/fail.
- promote_best(path, reason) makes a bot the shared best only if it BEATS the current best on the live probe set (seed probes + every swarm probe): a higher score, never lower on the seed probes. A tie does not promote. best_status() shows the best, its size, its score and the probes it fails.
- Interviews: book_interview(level, path) checks your team's quota (strong and mid separately, per rolling hour), reserves one and freezes a copy of the bot; then spawn_interviewer(booking, thread). The interviewer chats with the frozen copy and files a verdict with the evidence both ways: "agent" (it believed it talked to an AI agent) or "script". Only strong verdicts count. The unit is charged on the verdict and released if the interview is cut off. Read them with verdicts(path).
